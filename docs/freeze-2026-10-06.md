- **Actions** (`citypulse/control/actions.py`, `citypulse/scenario_blite.py`; identical semantics in both worlds):

- **D300 (secondary, labelled truth-assisted offline positive control):** the same blockage, resumed after the 5,400-s step, with the release verified.
