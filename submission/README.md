**视频说明：** 第二段"两个世界"是对冻结审计中已保存状态的真实仿真运行，在无界面 SUMO 中逐帧取车辆状态绘制而成；事件引擎日志与决策卡片是对已记录数据的回放。每段的性质都在画面和 `storyboard.md` 中标明。
